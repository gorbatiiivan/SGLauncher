# STARt Game Launcher
Lightweight launcher for eXo collections.


 * Supports All eXo Collections & LaunchBox Games(DOSBox games configured in LaunchBox are not supported).
 * Create Your Own Lite Version of Any eXo Project.
 * Theme Support & UI Customization.
 * SGLauncher is fully portable without need of installing system dependencies.
 * User interface is fast and light on resources, even with large libraries.

For corectly showing installed games need to add specify name folders (located in TrayMenu/Options/Specify folder).

Example: 

!dos;!win3x;!win9x;!IF;!appleiigs;!DREAMM;!ScummVM;!demoscn


------------------------------------------------------------------------------------------------------

For corectly showing language pack need to add specify name folders (located in TrayMenu/Options/Specify languages folders)

Example: 

!german;!spanish

etc...

------------------------------------------------------------------------------------------------------

No installation required, just move the SGLauncher folder to your LaunchBox folder.

Example: 

         D:\LaunchBox\eXo\
         
         D:\LaunchBox\SGLauncher\SGLauncher.exe
         
         D:\LaunchBox\SGLauncher\torrents\
